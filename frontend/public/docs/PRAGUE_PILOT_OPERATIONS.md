# SECTION 2: VERIFICATION SOP (Standard Operating Procedure)

## 2.1 Pre-Verification Checklist

```
BEFORE LEAVING:
□ Phone fully charged (100%)
□ GPS enabled
□ Camera app tested
□ Timestamp camera app installed (recommended: Timestamp Camera)
□ Address confirmed on Google Maps
□ Listing URL saved (if provided)
□ Customer's specific requests noted
□ Appropriate checklist downloaded/printed
```

## 2.2 Package-Specific Checklists

### QUICK CHECK (€9) - 15-20 minutes on-site

```
□ ARRIVAL
  □ Screenshot GPS coordinates on arrival
  □ Photo of yourself at location (timestamp visible)
  
□ EXTERIOR DOCUMENTATION
  □ Full building facade (wide shot)
  □ Building entrance
  □ Building name/number plate
  □ Street name sign
  □ Street view (both directions)
  □ Mailboxes/Intercom panel
  □ Immediate surroundings

□ BUILDING ACCESS (if possible)
  □ Entrance hallway
  □ Elevator/stairs
  □ Floor corridor
  □ Apartment door (number visible)

□ GPS PROOF
  □ Screenshot of maps app showing location
  □ Coordinates: ___°N, ___°E
  □ Time: ___:___

□ NOTES
  □ Building condition (1-5): ___
  □ Neighborhood feel: _______________
  □ Any red flags: _______________

DELIVERABLES: 10-15 photos, GPS proof, brief written summary
```

### LIVE WALKTHROUGH (€19) - 30-45 minutes on-site

```
□ EVERYTHING FROM QUICK CHECK, PLUS:

□ INTERIOR ACCESS REQUIRED
  □ Contact landlord/seller in advance if needed
  □ Schedule appointment time

□ INTERIOR DOCUMENTATION
  □ Entrance/hallway from inside
  □ Living room (3+ angles)
  □ Kitchen (full view + appliances)
  □ Each bedroom (2+ angles each)
  □ Each bathroom
  □ Storage/closets
  □ Balcony/terrace (if applicable)
  □ Windows/view
  □ Any damage or issues (close-ups)

□ VIDEO WALKTHROUGH
  □ 5-10 minute continuous video
  □ Start at entrance, walk through entire space
  □ Narrate what you see
  □ Show each room
  □ Point out anything notable

□ CONDITION CHECK
  □ Walls: □Good □Fair □Issues
  □ Floors: □Good □Fair □Issues
  □ Windows: □Good □Fair □Issues
  □ Doors: □Good □Fair □Issues
  □ Kitchen appliances: □Working □Not tested □Issues
  □ Water (run taps): □Good pressure □Low pressure □Issues
  □ Lights: □All working □Some issues
  □ Heating: □Present □Absent □Not tested
  □ Smells: □Normal □Smoke □Mold □Other:___

□ LISTING COMPARISON
  □ Room count: Listed ___ Actual ___
  □ Size feels: □Accurate □Smaller □Larger
  □ Furniture: □As shown □Different □Missing items
  □ View: □As described □Different
  □ Amenities: Check each listed item

DELIVERABLES: 25-40 photos, 5-10 min video, full report with 
checklist, listing comparison
```

### DEEP VERIFY (€39) - 60-90 minutes on-site

```
□ EVERYTHING FROM LIVE WALKTHROUGH, PLUS:

□ EXTENDED VIDEO (15-20 min)
  □ Detailed walkthrough with commentary
  □ Close-ups of all details
  □ Test all appliances on camera

□ LIVE VIDEO CALL (if customer requested)
  □ Schedule time with customer
  □ WhatsApp/FaceTime call from location
  □ Let them direct what to see
  □ Answer questions in real-time

□ DETAILED INSPECTION
  □ Open all cabinets/closets
  □ Check under sinks for leaks
  □ Test all electrical outlets
  □ Check window seals
  □ Inspect for mold (bathroom, kitchen, windows)
  □ Check water heater/boiler
  □ Test heating/AC if possible
  □ Check internet connection (if router present)
  □ Test doorbell/intercom

□ NEIGHBORHOOD ASSESSMENT
  □ Walk around block
  □ Nearest metro/tram stop (distance, name)
  □ Nearest grocery store
  □ Nearest pharmacy
  □ General neighborhood vibe
  □ Noise level observation
  □ Parking situation
  □ Building security assessment

□ DOCUMENTATION CHECK (if accessible)
  □ Energy certificate visible?
  □ Building notices in common areas?
  □ Any construction/renovation signs?

DELIVERABLES: 50+ photos, 15-20 min video, live call recording 
(if applicable), comprehensive report, neighborhood info, 
premium certificate
```

## 2.3 GPS/Timestamp Proof Protocol

```
REQUIRED PROOF FOR EVERY VERIFICATION:

1. TIMESTAMP PHOTO
   □ Use "Timestamp Camera" app
   □ Shows: Date, Time, GPS coordinates
   □ Take at building entrance
   □ Take inside apartment (if access)

2. GPS SCREENSHOT
   □ Open Google Maps
   □ Let location settle (blue dot accurate)
   □ Screenshot showing:
     - Your location dot
     - Address visible
     - Coordinates visible (tap blue dot)

3. METADATA PRESERVATION
   □ Do NOT edit photos
   □ Keep originals (EXIF data intact)
   □ Upload directly from phone to Google Drive

4. VERIFICATION SELFIE (optional but recommended)
   □ Quick selfie at building entrance
   □ Proves agent was physically present
   □ Building visible in background
```

# SECTION 8: TROUBLESHOOTING

## Common Issues & Solutions

```
PROBLEM: Can't access building
SOLUTION: 
- Document exterior thoroughly
- Note in report "Interior access not available"
- Offer partial refund or reschedule

PROBLEM: Landlord/seller is suspicious
SOLUTION:
- Be professional and transparent
- Explain you're verifying for a potential tenant/buyer
- If they refuse, document and move on

PROBLEM: Location doesn't exist / wrong address
SOLUTION:
- Document the situation (photos of where address should be)
- Contact customer immediately
- Flag as potential scam indicator
- Full refund if we can't verify anything

PROBLEM: Customer wants something we don't offer
SOLUTION:
- Be flexible in MVP phase
- If reasonable, do it and charge custom price
```
